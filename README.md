# 追帧 · ChaseFrame

免费 AI 构图相机。打开就能拍，实时告诉你「往哪挪、什么时候按」，自动配曝光参数，还能预判运动轨迹、连拍挑出最清晰的那一帧。

> 参考 Doka 相机的构图/滤镜思路做的免费替代品，但**没有登录、没有会员、没有次数限制、没有云端上传**。

## 完整能力

1. **构图指导（圆圈进框）**：主体画成一个**白圈**跟着走，目标位置画成一个**琥珀色方框**（带虚影圆圈）钉在画面里。方框在第一次认出主体时就定死，之后**不会随手机平移而移动**——你移动手机，圆圈朝方框靠，箭头指出方向、文字写清「手机往哪移」，框变绿就是到位，可直接按快门。点一下方框可以换一个目标位置；切换场景或构图会自动重取。**跟手延迟约一帧**：帧差区域是「上一帧 ∪ 这一帧」的并集，中心天生落后半帧，已按估计速度补偿回去；分析频率会随机器性能自适应（约 18–30fps）。
2. **参数自动化**：按画面亮度算曝光补偿，按运动速度算快门下限，按灰世界估色温。支持硬件直写的机型会真的改摄像头参数（界面显示「硬件」），不支持的机型自动降级为软件提亮 + 参数建议（显示「软件」）。
3. **运动追焦**：帧差找运动块 → 连通域合并 → 质心速度 → 0.2s / 0.42s 双预测框，提前量直接画在取景框上。
4. **运动构图**：运动模式下主体自动放在运动反方向，前方留出空间（leading room），这是拍跑步、骑行、宠物最常用的构图法。
5. **连拍选优**：运动模式单击快门即连拍 10 张，逐帧算拉普拉斯清晰度，自动选中最佳那张，其余可一键全存。
6. **手动锁定主体**：复杂场景（背景很抢眼、主体偏小）长按取景框，直接把那个位置锁定成主体，构图提示立刻以它为准；再长按一次取消。**点方框**则换一个构图目标。
7. **737 组滤镜 + 22 套风格**：80 个母版 × 8 个变体，分基础 / 胶片 / 黑白 / 流行 / 夜拍五组，含 Portra 全系、Gold 200、Ektar 100、Velvia、Classic Chrome、CineStill 800T、富士 FXN-R/CC/NN、CCD 千禧、和光、徕卡暗调、莫兰迪、港风、Y2K 等；带搜索、收藏、精选 40 组。点「风格」一次把滤镜、画幅、拍摄模式、构图一起配好。
8. **15 种构图法**：三分、黄金分割、中心、对角、运动留白、视线留白、对称、三角、框架、满构图、破局、负空间、S 形曲线、层次，选中的构图会以虚线画在取景框上。
9. **AI 构图（静态图片分析）**：评分行右侧「AI 构图」按钮 → 冻结当前帧或选一张本地图片 → 识别主体占比/位置/留白/重心 → 列出构图问题 → **主体画成圆圈、目标位置画成方框，箭头指出方向，文字直接告诉你手机该往哪移**（手移动方向与主体移动方向相反）→ 可切景别按建议重新裁切出片。只处理静态图片，不做实时追踪。
10. **视频模式**：照片/视频切换，录制时保留滤镜与构图辅助，录完进相册，可回看、保存。

## 手机怎么用

### 网页版
1. 用手机浏览器打开部署好的链接（或本机：`start.bat` 后访问 `http://电脑IP:8099`）
2. 允许相机权限 → 点「开启相机」
3. 浏览器菜单 →「添加到主屏幕」，之后从桌面图标全屏进入

### APK
1. 把 `ChaseFrame-1.2.3.apk` 传到手机安装（需允许「安装未知来源应用」）
2. 首次打开授予相机权限
3. 拍完的照片自动存到 `相册/Pictures/ChaseFrame`

> APK 使用的是自签名证书。若系统提示「未知开发者」，属正常现象，选择继续安装即可。

## 界面上那些数字是什么

- **左上参数条**：`ISO / 快门 / EV / 色温`，标签显示「硬件」表示这些值已经写进摄像头，显示「软件」表示是算法建议值 + 软件提亮。
- **分数环**：构图综合分，≥86 且稳定约 0.4 秒会把快门圈点亮成绿色（此时按快门最容易出片）。
- **主体框**：算法认定的主体范围，括号里是它占画面的面积比。
- **青色虚线框**：运动主体的当前位置与预测位置，`移动 xx%/s` 是它在画面里的速度。
- **橙色十字圆**：当前构图方案建议把主体放到哪里。

## 已知边界（实话实说）

- **主体识别是启发式的**：靠色彩、边缘、中心先验和运动区域打分。背景里有太阳、白墙、大片同色天空时，偶尔会认错主体 —— 这时长按取景框手动锁定即可，比算法可靠。
- **连拍速度受限于机型**：网页端每帧要经过画布合成，一般 20fps 左右；想拍更快的动作，建议直接用系统相机的连拍，再用这里的构图建议。
- **没有防抖**：手机端依赖光学防抖；画面偏软时界面会提示“稳住手”。
- **目标框是锁定的**：为了让你能安稳地把圆圈挪进去，方框一旦定下就不再跟着主体跑。这也意味着主体在画面里走动时，提示可能一直指着同一个位置 —— 想换就点一下方框，或切换一次场景。

## 关于「自动设置参数」的实话

浏览器的相机接口（`MediaStreamTrack.applyConstraints`）能拿到的能力因机型而异：

| 参数 | 常见支持情况 | 不支持时的处理 |
|---|---|---|
| 曝光补偿 EV | 多数安卓 Chrome 支持 | 软件提亮/压暗（烘进照片） |
| 变焦 | 普遍支持 | 禁用变焦按钮 |
| 手电筒 | 部分支持 | 提示不支持 |
| ISO / 快门 | 极少（需 manual 曝光模式） | 给出建议值 + 用连拍与选帧弥补 |
| 白平衡色温 | 极少 | 用滤镜色偏近似 |
| 点对焦 | 部分支持 | 提示靠近主体 |

所以「自动参数」在这款应用里是**能直写就直写、不能直写就给建议并用算法补**。这也是为什么运动场景重点做了连拍选优——因为快门速度没法硬控时，多拍几张挑最清晰的才是真正有效的办法。

## 版本号怎么走

版本号只维护一份：`version.json`。改完东西跑：

```bash
node scripts/bump.mjs        # 1.1.1 → 1.1.2（修订号 +1）
node scripts/bump.mjs minor  # 次版本 +1
bash android/build.sh        # 产出 ChaseFrame-<新版本>.apk
```

`bump.mjs` 会同步：`version.json`、`android/AndroidManifest.xml`、`harmony/AppScope/app.json5`、`index.html` 的 `app-version`、README 里的安装包文件名；`build.sh` 直接从 `version.json` 读版本号与 versionCode。

## 本地构建 APK

不需要 Android Studio / Gradle，脚本直接调 aapt2 + javac + d8 + apksigner：

```bash
bash android/build.sh
```

依赖的工具链在本机 `.toolchain/sdk`（JDK 17 + build-tools 35 + platform 35）。产物为根目录 `ChaseFrame-1.2.3.apk`。

网页资源会被打进 `assets/www`，App 内通过拦截 `https://appassets.androidplatform.net` 从 assets 直读，不联网、不申请网络权限。
